# Moooments 📸

Moooments is a private photo-sharing platform for event attendees. Guests can upload photos into albums, accessible only to those with event codes or invites — perfect for weddings, birthdays, and private gatherings.

## 💡 Use Case
Organizers or hosts create albums; guests upload, view, and comment on shared memories in a controlled space.

## 🛠️ Tech Stack
- **Frontend**: Next.js, Tailwind CSS, Framer Motion
- **Backend**: Django 
- **Database**: PostgreSQL
- **Cloud Storage**: AWS S3

## 🚀 Features
- 🔐 Private Event Albums
- 🖼️ Fast Image Upload + Optimization
- 📤 Multi-Device Upload Support
- ✨ Elegant, Mobile-Friendly UI

## 📈 Project Results
- 🧍 Used in 3 events; 500+ photos uploaded by 30+ attendees
- 🔐 100% of hosts preferred private access over public links
